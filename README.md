# My First Android Application

This is my first Application. 
The application's purposes are learning code and using Android Studio.

## 🎯 Project Purpose
The main goal of this repository is to understand the basics of Android development, master the IDE interface, and practice writing clean Java code. 

Currently, the application includes:
* **Floating Action Button (FAB)** implementation.
* Handling user click events with `OnClickListener`.
* Displaying lightweight feedback using the Android **Snackbar** component.

## 🚀 Features
* **Interactive FAB:** A floating button that responds instantly to user interaction.
* **Native Snackbar:** Displays the message *"Just another option for button."* using the default Material Design settings.

## 🛠️ Built With
* [Android Studio](https://android.com) - The official IDE for Android development.
* **Java** - The core programming language used for the application logic.
* [Google Material Design](https://github.com) - For layout components and UI styling.

## 📝 What I Learned So Far
* How to link XML layout components with Java background logic using `findViewById`.
* How the Android layout hierarchy handles the `View` parameter to render components like a `Snackbar`.
* Basic project management and structure inside Android Studio.
